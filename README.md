# 九州志项目总览

《九州志》是面向长期共同创作的东方奇幻 IP，气质是**壮阔、有烟火气、保留希望**。当前工作稿 **v0.8**，2026年11月16日修订：**《补天记》确立为整个世界的第一本小说**，下一阶段集中完成这部长篇。

## 先读故事

一个土部落的年轻人误入冥界，看见死者不得安息，也遇见在地下求生的九黎。重返人间、接触女娲之后，主角带着寻找五色石的任务走入水火战争和木的世界，逐渐明白魂灾与活人的生活相连。最终，土族与黎族双主角各自作出选择，在补天中成为真正的土神与金神，使生与死重新连接。

从[故事总纲](03_故事创作/补天长篇/故事总纲.md)进入；人物的欲望、冲突与高光候选见[人物与冲突](03_故事创作/补天长篇/人物与冲突.md)，秘密如何逐步显露见[伏笔与揭示](03_故事创作/补天长篇/伏笔与揭示.md)。目标约百万字，分卷与人物姓名尚未锁定。

全书通过人物经历传递世界背景、五行规则与力量、生灵种族、风土人情、部族内部的人神关系，以及基础地理框架。具体的[呈现安排与写作次序](03_故事创作/补天长篇/故事总纲.md#story-world)与总纲共同维护。

## 本轮删改与来源

只有当前这条补天主线。旧版“两阶段补天”、先禁神再通归、神农后轩辕前等衔接已撤出；不会再以它们反向约束故事。删改理由及完整旧稿见[精简记录](归档/2026-11-16_主线精简记录.md)。来稿与对话原文见[来源索引](资料/补天来稿索引.md)。

神话、传说、史诗及其后的近代仍是整个 IP 的时代方向。《补天记》的首作定位替换原先的近代首作意向；近代保留为后续作品空间，具体历史衔接留待故事需要时展开。
