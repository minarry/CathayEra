# 九州志项目总览

《九州志》是面向长期共同创作的东方奇幻 IP。当前为文档整理版 v0.5，整理日期 2026年11月15日；这是文档版本，尚未发布完整世界正典。创作者明确输入与推荐解释分别保留，重组不改变设定的批准状态。

## 本地资料库

双击[九州志资料库](九州志资料库.html)可离线阅读、搜索全文、查看页面引用与修改影响，并按文档、原图和归档筛选。Markdown 文件仍是正文的唯一维护位置；修改或新增资料后，双击[更新资料库](更新资料库.cmd)重新生成，再刷新浏览器。生成工具位于“资料库”目录，不保存另一套世界设定。

## 维护原则

同一设定只在主条目维护全文，其他文档引用。具体修改入口见[文档归属表](00_项目管理/协作与版本管理.md#doc-ownership)。新稿不得以“补充整合”的名义另存一份相同规则或总年表；正文试写也不得悄悄批准未决方案。

默认创作资料范围为上表中的现行文档。核对创作者原意时查[神话输入提要](资料/神话设定输入记录.md)、[概念澄清提要](资料/规则与存在澄清记录.md)及其原图；旧方案仅在需要追溯时查[归档与迁移记录](归档/重组记录.md)。

首作、完整地理、若干机制和正式正典尚未定稿，实际 AI 自动流程尚未部署。当前选择状态只在[决策与待办](00_项目管理/决策与待办.md)维护。
