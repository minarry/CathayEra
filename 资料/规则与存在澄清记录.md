# 九州志规则与存在澄清记录

来源：创作者对设定图和核心概念的直接澄清。以下为提要；最新明确边界优先于此前 AI 候选。此页只记录输入，不保存另一套现行解释。

## 创作者明确提供的边界

| 编号 | 内容 |
| --- | --- |
| C01 | 方形代表规则。原始层包括时、空、阴、阳；五行属于世界基本规则，具有比具体物质更深的内涵。 |
| C02 | 圆形代表存在。具体的水、火、大地、日月、山河、植物与兽，都是规则交织在现实中的实现。 |
| C03 | 灵与魂都是真实存在的实体，即使有时不可见、不可触；二者有生有灭。灵是生灵之本，魂来自生灵，常经生死转化，是神性之本。 |
| C04 | 存在的变迁可能使新的规则形成，木与金的产生与生灵、魂及神性演化密切相关。 |
| C05 | 需要限制后天规则、先天规则与原始规则的关系，同时保留世界演化和未来创作的空间。 |
| C06 | 可以为逻辑一致性适当调整故事与旧设定，不要求保留已经造成概念混淆的旧解释。 |

“先天”与木金演化先后的现行整理见[规则层级](../01_世界设定/规则与存在.md#ont-02)。这是对输入的工作解释，不倒写成创作者原话；旧 D01 已退出当前待决清单。
