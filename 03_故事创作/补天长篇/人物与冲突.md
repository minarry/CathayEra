# 补天记人物与冲突

本文维护人物方向与场景候选，不重复[故事路线](故事总纲.md)。人物姓名、性别、亲缘、爱情与具体过错仍待塑造；表中的欲望是写作抓手，不是人物只能拥有的唯一动机。

<a id="story-leads"></a>
## 双主角

| 人物 | 初始处境与欲望 | 可以发展的内在冲突 | 必须保有的主动性 |
| --- | --- | --- | --- |
| 土族主角 | 从有具体生活的家园出发，初入冥界时想活着回去；所见动摇了对死亡与庇护的信任 | 眷恋熟悉的人，却逐渐看见家园之外的人也有归处；承担更大的事会改变自己的生活 | 对女娲的任务作出自己的理解，决定为何再次离家，成长为土神 |
| 黎族主角 | 从地下九黎的真实生活出发，有需要保护的人和自己的未来，能理解外人看不见的危险 | 认同族人的创伤，却必须面对以创伤之名造成的新伤害；改变现状可能被亲近者视作背叛 | 决定与土族主角合作的条件，对地下众生有独立责任，成长为金神 |

土族主角可以误判地下，黎族主角也可以误判地表；成长来自修正认识并承担后果。两人不必在每个问题上轮流正确，黎族主角也不必等土族主角教导才产生道德判断。

私人愿望应小到可以落成场景：回去赴一个约、照顾某个人、完成一件一直被打断的事。具体选哪一种留给写作，避免先用亲人被杀、隐藏血统和宿命爱情统一启动所有人物。

## 需要发展的关系

以下是关系位置，可合并、替换，不要求各创造一个固定配角。

| 关系位置 | 人物有价值的复杂性 |
| --- | --- |
| 主角家乡的人 | 能给予爱和保护，也可能害怕接纳九黎；不因观念有限就被写成愚民 |
| 九黎与鬼的技艺创造者 | 曾真实救助他人，如今可能妥协、被利用或主动参与控制；功绩与责任同时存在 |
| 有独立意愿的鬼 | 会感谢、愤怒、依恋或拒绝；它不只是供活人争论的受害样本 |
| 为九黎争取未来的人 | 复仇、回归、保全后代可能都出于真实牵挂；分歧来自经历和选择，不靠阵营标签 |
| 水火共同体中的同行者或对手 | 享受文明的成果，也会被职责、资源和战事卷入；理解代价之后仍可能选择继续作战 |
| 木的见证者 | 保存过别人失去的历史，也有没见到、记错或不愿讲述的部分；可以帮助，却不能代替主角判断 |
| 女娲与其他神 | 与众生有历史和关系，也有不能包办一切的限制；不提前决定谁在幕后操纵全部事件 |

<a id="story-highlights"></a>
## 保留的高光候选

这些场景保留张力，尚非已经发生的剧情。采用时应落到具体人物，选择不合适可以撤换。

**H01 地下的一顿饭。**主角第一次在地下被当作客人招待，饭食、照明、座次都让人不习惯。席间有人温和地谈论明天要带鬼返回地表。读者先相信这是一群在认真生活的人，再意识到他们准备做的事可能伤害别人。

**H02 救人者手中的束缚。**一个被视为残酷控制者的人，能准确辨认鬼即将溃散的征兆；鬼也愿意向其求助。但当鬼提出离开时，对方以“只有我能救你”为由拒绝。真实的照护使控制更难割舍，也使责任更具体。

**H03 得偿之后仍未安宁。**一个鬼终于面对执念中的人或地方，某种痛苦确实缓解，其他声音却没有消失。它没有证明一切承诺都是骗局，却推翻了一个答案可以适用于所有鬼的想象。

**H04 同一炉火的两种去处。**战地见到的伤人器物，与家乡日常器具出自同一门手艺。匠人有自己的处境，受害者的伤也不会因为理解匠人而减轻。场景应让角色选择，而不只展示象征。

**H05 没有完整见证者的历史。**主角向长寿者求一个明确答案，却得到几段彼此冲突、各有证据的记忆。一位曾经救人者也参与过另一场驱逐；一个被误解的人并非因此无辜于所有事。主角需要带着不完整的知识继续行动。

**H06 家园仍然温暖。**归土之后，熟悉的人准备好主角爱吃的食物，一切似乎允许旅程结束。恰在这样真实的安稳里，主角决定再次出发。不要为了方便出发，先把家园写成虚伪的骗局或全部烧毁。

**H07 新主体说出自己的名字。**人们为了从一个鬼体内救回熟悉的亡者，准备替它决定命运。鬼第一次说出与任何旧魂都不同的自称。这个声音使原本自认为善良的计划必须改变；新的办法仍要面对现实困难。

**H08 补天之后的普通告别。**在宏大的变化之后，回到一个前文认识的普通人身边。他仍会悲伤，却终于知道死者有了去处，自己可以继续生活。希望由前后的差别产生，不靠旁白宣告世界完美。

<a id="story-responsibility"></a>
## 保住复杂性的方法

每个重要角色都应有具体想保护的东西、做过的选择，以及选择造成的后果。被迫与主动、知道与不知道，应影响对责任的理解；背景创伤不能自动抵销后来伤害。

和解可以有限，合作不要求相互原谅。受害者拒绝和解不应被写成妨碍大局；人物改变也不能只靠临终坦白或一句“原来都是为了你好”。让利益、依恋和错误判断进入行动，复杂性自然会出现，不需要人人背后都藏一个大阴谋。
