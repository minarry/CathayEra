# 补天记故事总纲

《补天记》是《九州志》世界的**第一本小说**，目标约 **100万字**，气质为壮阔、有烟火气、保留希望。它既讲完双主角补全天地生死秩序的故事，也让首次接触九州志的读者建立对这个世界的完整基础认识。下列分段用于组织因果，卷数和章节配额尚未锁定。

<a id="story-cause"></a>
## 一条主线

土部落的年轻人在熟悉的生活中长大，误入冥界，发现死者并没有如家乡所相信的那样安息。在那里，遭迫害后进入地下的九黎与痛苦的鬼共同生存，也相互依赖、争夺和利用。

初次返回人间后，主角接触女娲，接受寻找五色石的任务。旅程经过水火文明与战争、木的世界，再回到土族家园。最初看起来只发生在地下的灾难，逐渐显露出与活人生产、繁衍、争斗和记忆的联系。

黎族主角有自己的家园、关系与目的，不能只作为带路人加入土族主角的使命。两人的同行、分歧与合作，使最后的补天既能回应活人的生活，也能回应死者和地下众生的处境。

最终，两人再入冥界，在补天中成为真正的土神与金神，使五神格局完整、生死重新连接。他们完成自己逐渐理解并选择承担的事，而非让旧神借身体完成早已写好的计划。

<a id="story-volumes"></a>
## 七段推进

| 段落 | 主要经历 | 认识与选择怎样推动下一段 |
| --- | --- | --- |
| 一、土中生 | 家园、亲缘、日常劳作与成长；一次意外使主角进入冥界 | 先建立主角真正想回去的生活，死亡随后才有具体分量；意外原因待写 |
| 二、金与冥 | 看见魂的淤积、鬼的痛苦、九黎的生活及其与鬼的关系；进入黎族主角的故事 | “回到地表”仍是愿望，但主角已经带回无法回避的见闻；两人的初次关系尚待设计 |
| 三、初返与受命 | 离开冥界后接触女娲，获得寻找五色石的任务 | 神谕给出方向，却不替他们解释一切；地下经历成为判断任务的依据 |
| 四、水火之间 | 亲见水火改善生活、组织文明，也被用于争夺和战争；五色石的寻找进入具体利益关系 | 想解决地下的困境，就不能回避地上的伤害；两人对救谁、先做什么可以产生分歧 |
| 五、木中长年 | 接触更长的生命、不同的历史记忆，以及延续与改变的代价 | 理解生命的延续不等于保留一切旧事；获得重新思考故乡、遗存与补天的条件 |
| 六、归土 | 回到土族与圣地；重看最初信仰、家园和任务，整理旅程所得 | 回家曾是终点，现在必须决定是否、以及为何再入冥界；土金力量的理解在此走向成熟 |
| 七、再入冥界与补天 | 地上地下的冲突汇合，五色石与此前建立的能力、关系发生作用 | 两位主角各自作出不可由对方代替的选择，成为土金二神，打通生死联系，并留下真实后果 |

水火段可以拆成数卷，木与归土也需要足够生活和人物篇幅。原参考稿的十卷分配保留作素材，不再把每个卷名、比例和候选场景作为约束。

<a id="story-world"></a>
## 随故事建立世界认识

全书需要让读者理解六个方面，并看见它们如何相互影响。主线所用到的因果、能力和历史必须解释充分；更远的地理、后世制度及不影响结局的创世秘密可以继续留白。

| 内容 | 怎样进入人物经历 | 全书结束时应形成的认识 |
| --- | --- | --- |
| 世界背景 | 先接触家乡传说与仪式，再遇到遗存、不同见证和神；前后认识相互修正 | 世界如何走到生死失衡，现有神与先天神有何关系，补天究竟改变了什么 |
| 五行规则与力量 | 在劳作、照护、行旅和冲突中见到实际效果，再通过失败与合作理解条件 | 分清规则与具体物质，理解五行各自能做什么、受到什么限制，以及何以需要协同 |
| 生灵种族 | 与具体的人、妖、灵族、九黎和鬼共处，看见身体差异如何影响生活 | 分清生命来源与文化归属；理解灵、魂、鬼、神的基本差别，认识不同生命的主体性 |
| 风土人情 | 通过吃住、交易、劳作、节令、亲缘和生死礼俗进入当地生活 | 地方习惯有生计、环境和历史原因，同一族群内部也存在差异 |
| 部族内部的人神关系 | 写出受庇护者、承担祭祀者、解释神意者和持异议者之间的具体关系 | 神给予了什么，人付出了什么；信仰怎样影响分配、权威和个人选择，神自身又有哪些意愿与限制 |
| 基础地理 | 由出发、绕行、渡河、入冥、战争与回乡逐步建立空间感 | 知道主要地区怎样相连，地表与地下如何往来，山河、路程和季节为什么会影响决定 |

开篇用土族的日常建立读者最早的判断；金与冥界使这些判断遇到反例；水火段展开文明、力量与战争的联系；木提供更长的生命经验；归土让熟悉的地方获得新的意义；最后由补天兑现前文逐步建立的理解。各段的行动因果仍以上面的七段推进为准。

每段以某种力量或生活经验为重心，但五行应当交织存在。土族家园同样需要水、火、植物与器物；读者可以在尚不认识名称时先看见其作用，之后逐步理解。普通物质的变化也不全部归为神迹。

五行力量的呈现采用“**有用的本领 → 遇到限制 → 承担代价 → 与其他力量配合**”的思路。重要能力进入高潮前，要让读者见过足够的用途和边界；法术的具体定义仍只写入[规则主条目](../../01_世界设定/规则与存在.md)，避免在剧情稿中暗增万能效果。

一个场景只要有真实的目的，就能同时承载几层认识。例如，候选的渡河冲突可涉及船行、水势、季节、通行权与祭祀分歧；先写人物为何必须过河、有人为何不肯放行，再让世界细节影响解决方式。不同场景承担不同重点，不要求每章讲齐六项。

<a id="story-writing"></a>
## 从开篇走向全书

下一步先完成“土族家园—初入冥界”的开篇故事段：建立土族主角想守住的日常和一次具体行动，让入冥从这次行动中发生；同时塑造黎族主角已有的生活、牵挂与选择。开篇可以出现一则传说或一次仪式，但知识必须服务当场的人和事。

先选定开篇用到的人物、力量边界和局部道路，再试写一组连贯章节，检验语气、节奏和世界细节是否自然。用试写中成立的人物关系推动全书细纲，并提前建立补天方法与代价所需的铺垫。之后按故事段持续写作、修订和回写公共事实，直到全稿与通读修订完成。

这里的工作顺序不增加新的审批关卡，也不要求先编完世界百科。具体任务状态仍集中于[决策与待办](../../00_项目管理/决策与待办.md)。

## 三条贯穿的冲突

**救助与支配。**九黎的技艺确实帮助过鬼，部分使用者也借它取得支配。要摆脱控制，必须同时面对失去稳定的风险。角色需要找到具体出路，不能只靠揭露坏人就解决困境。

**繁荣与代价。**水火创造的生活值得珍惜，战争造成的伤害也必须由具体的人承担。主角可以理解一种文明，却拒绝它正在做的事；同伴也可能为了保护真实的家人而作出伤害别人的选择。

**延续与告别。**木保存的经验、土承载的家园、金凝定的自我都可能成为拯救的条件，也可能变成拒绝改变的理由。让死者有去处，与强迫死者消失之间有区别；允许活人继续生活，也不等于命令受害者原谅。

<a id="story-finish"></a>
## 结局的落点

必须兑现：魂的困境真正改变；土族与黎族两位主角成为真实的土金二神；五神归位；两人各自的选择对结果不可替代。具体方法遵循[补天法则](../../01_世界设定/补天法则.md)，不在本纲另立一套机制。

结局应给人可看见的未来：一次不再令人恐惧的告别，一个终于能够安排明天的地下家庭，或一段不以控制维系的关系。这些是收束方向，不指定唯一场景。

尚不锁定水火木三神的最终命运、两位新神付出的代价，也不预定必须用爱情牺牲或主角永困一处换取圆满。胜利应能改变世界，同时让发生过的伤害继续有重量。
