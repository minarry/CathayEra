# 族群与文明

本文维护共同体的生活、利益、历史经验，以及当前故事需要的地理关系。生命来源见[生命与神圣存在](生命与神圣存在.md#life-04)，具体人物见[人物与冲突](../03_故事创作/补天长篇/人物与冲突.md)。

<a id="civ-axes"></a>
## 不把五行当作五个种族

族群的身体来源、修习的力量、信仰的对象、所属的政权可以互不一致。土部落不必只会土术，木的世界也不只容纳妖灵；共同体内部有人相信神，有人依赖技艺，也有人只关心下一季的粮食。

<a id="civ-five"></a>
## 当前故事需要的共同体

现行主线需要土族家园、地下九黎与鬼、水火文明、木的世界。原稿“五族之争”保留为历史称谓来源，其参战者与边界尚未明确；正文现阶段可称“诸部冲突”。这些共同体不预先划成五个国家，各部关系随故事需要确定。

<a id="civ-life"></a>
## 让力量进入日常

下表是生活设计方向，不是已固定的国家制度。

| 共同体 | 应先让读者看见的生活 | 随之出现的利益与冲突 |
| --- | --- | --- |
| 土族家园 | 土地、粮食、亲缘、照顾老幼和安葬死者 | 谁有留下的资格，家园如何接纳外来者 |
| 水的文明 | 捕鱼、航行、灌溉、河道贸易 | 上下游争水，迁徙者与定居者，通行与封锁 |
| 火的文明 | 炊火、取暖、制作器物、改善生产 | 燃料与劳役，技术带来的繁荣与战争能力 |
| 木的世界 | 不同寿命的生命共处，生长、养护和传承 | 谁能等待，谁已等不起；旧承诺能否约束后来者 |
| 地下九黎与鬼 | 求生、照护、稳定器物、地下的住处与往来 | 保护与依赖，遗民复仇、后代生活及鬼的自主性 |

地下的食物、通风和出入条件须在相关场景中写实，不能只凭偏阴体质抹去活人的需求。水火带来的改善同样应真实存在；战争有具体发动者、受益者和受害者，不能用“双方都复杂”抹平责任。

<a id="civ-faith"></a>
## 部族内部的人神关系

同一共同体里，真诚信奉某位神的人也会对供奉、分配、出战或迁徙产生分歧。神的庇护可以真实存在，解释神意的人仍可能误判，族人的感激也可能与不满并存。

写到具体部族时，先明确谁能接触神或遗存、谁解释回应、谁组织共同事务、谁付出代价，以及普通人遇到困难如何求助或反对。这些职责可以重合，也可以分散，不预设所有部族都有同样的首领和祭司制度。

土金共同体面对遗存，水火共同体与已有意志的神建立关系，其差异应产生不同的生活经验。一次祭祀可以同时包含敬爱、习惯、互助与权力安排；采用哪种具体形式，由相关人物和生计决定。

<a id="civ-geography"></a>
## 基础地理怎样建立

当前确定的是同一世界中地表与冥界的联系，以及[故事的行进次序](../03_故事创作/补天长篇/故事总纲.md#story-volumes)。行进次序不等于方位图，也不将五行各划成一块独占地貌的领土。

地理先分两步落实。开篇确定家园、生产与取水处、祭祀或安葬地点，以及进入地下的路径之间的实际位置，使人物行动可追踪。全书再接通水火地区、木的世界与归土路线，明确主干水系、山地阻隔、聚居地和地表地下的出入口；写到一个地区，再补足相关季节、资源、交通方式及旅程所需时间。

同一片区域可以有不同族群与力量传统。渡口、贸易地、边界聚落等交往地点能使不同文明在旅途中相遇。地形要影响粮食、资源、战争和求生，也让读者知道角色为何不能随意跳过一段旅程。

目前尚未绘制实际地图，也未确定各地区的方位、名称和距离。后续采用的地理事实在这里集中维护，故事稿只引用所需部分。

<a id="civ-jiuli"></a>
## 九黎的创伤与分歧

九黎遭受过严重迫害，进入地下不是自由选择的田园迁居。幸存者可能渴望复仇、返回故土、保全后代，或建立不再依靠地表许可的生活。这些愿望可以相互冲突，也可以同时存在于一个人身上，不必先划定几个整齐的派别。

与鬼共同创造的技艺，既能成为相互扶助的成果，也能形成新的控制关系。遭受迫害能够解释九黎的恐惧和选择，不能自动正当化对鬼或其他平民的伤害。鬼本身也有创造者、合作者、反抗者和改变主意的人。

<a id="civ-memory"></a>
## 木所保存的历史

妖族、灵族及其他长寿者能够保存活人难以见到的经验，但寿命长不等于全知。记忆有位置、偏见和沉默：同一场迁徙，对一些生命是失去家园，对另一些是获得生存空间。

木的段落应让主角接触这种有立场的历史，以及经历变化仍然选择延续生活的生命。它提供理解，不负责一次性揭晓全世界的秘密。
