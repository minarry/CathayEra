# 生命与神圣存在

本文定义灵、魂、生命与神。魂灾的处置和补天边界见[补天法则](补天法则.md)，共同体生活见[族群与文明](族群与文明.md)。

<a id="life-01"></a>
## 气、灵、魂

| 存在 | 当前定义 | 写作边界 |
| --- | --- | --- |
| 气 | 世界中可流动、交换、参与变化的存在 | 不再兼作一切力量、灵魂和规则的统称 |
| 灵 | 生灵得以生长、感受和活动的根本 | 有生有灭；不等同人格或记忆 |
| 魂 | 源于生灵、承载生命经历与执念的真实存在，通常经生死转化而显著成形；也是神性之本 | 不能用“只是一段信息”替代其实体性，也不能凭记忆复制一个原本的死者 |

生死可以使灵、魂、形体之间的关系改变。“通常经历生死”不等于所有魂只能在死亡瞬间出现；但先天神如何形成魂，暂留未写明的起源环节，不为填补这处空白追加一套特殊生命史。

<a id="life-02"></a>
## 孤魂与鬼

魂不能顺利消散或继续转化，便可能积聚。不同魂的情绪和执念相互牵扯，能够自然形成鬼：有的保有较清楚的自我，有的充满互相冲突的声音，甚至反复溃散、重组。

**鬼的出现早于九黎对鬼的利用。**鬼的强大与痛苦可以来自同一状态，不能以战斗能力判定其自由或幸福。稳定后的鬼可能逐渐形成独立意愿；不能因为它由多个魂构成，就认定它没有自己的生命价值。

认出熟人的记忆，不足以证明完整的熟人仍在那里。救治、分离和保留一个新主体可能发生冲突，具体案例应在故事中辨认，暂不制定一套包办所有情况的身份公式。结局也不承诺所有死者复原。

<a id="life-03"></a>
## 魂与金的关系

保留“魂的凝聚与金的成形有关”的早期演化方向。它说明金与保存、收束、分辨有深层联系，不表示每一块普通金属都囚禁着死者，更不表示杀人就能稳定、无代价地制造金属。

<a id="life-04"></a>
## 人、妖、灵族与九黎

| 称谓 | 当前用法 |
| --- | --- |
| 人 | 女娲创造的生命，五行皆备，能够运用五行；这不构成其他生命低等的依据 |
| 妖族 | 植物一脉发展出的有灵智者 |
| 灵族 | 动物一脉发展出的有灵智者；与“灵”这种存在区分 |
| 九黎／黎族 | 体质偏阴的活族，在冲突和迫害中几近覆灭，遗民进入冥界求生 |
| 仙 | 生灵修习并维系自身延续的一种可能成就；并非新生物种，也不等于绝不会死亡 |

妖、灵有不同起源，不要求统一文化、政治归属或道德倾向。九黎不是鬼族，地下也并非只有九黎和鬼。旧图中的“精灵、兽人”不自动成为现行种族。

<a id="life-05"></a>
## 神的起源与力量

伏羲与女娲是最早的先天神，源于阴阳。两者都是存在，不等于阴阳规则本身。伏羲先因尚未写明的变故沉睡；女娲造人后也进入沉睡。

此后生灵繁衍、死亡，生活对水火的广泛运用，与魂的积聚共同构成水火神兴起的背景。木神伴随生命的发展逐渐出现。具体成神过程尚未细化，不把“使用某元素”或“信徒达到某数量”写成自动生成神灵的公式。

神与生灵的关系可以包含教导、庇护、依赖、利用和争夺。信仰能使这种联系加强，也可能改变神与共同体；它不是无限能源，更不证明所有神只能靠杀死信徒成长。

<a id="life-legacy"></a>
## 土金遗存与双主角

故事开始时，土族奉为土神、九黎奉为金神的对象，分别与女娲、伏羲遗留的意志和规则作用有关。它们尚不是两个完整、独立的土神与金神。信徒可以把遗存理解为正在注视自己的神，这种认识差异可进入剧情。

土族与黎族双主角在经历中逐渐掌握力量，最终在补天中成为真正的土神与金神。他们保有自身的选择和成长，不预设为旧神转世、附体容器或早已注定的神之化身。“五神归位”也不意味着世界从此只能有五位神。

<a id="life-06"></a>
## 暂不展开的部分

修仙流派、后世宗教和神格等级暂不承担《补天记》的解释任务。需要它们的作品再发展对应条目，不用后世体系倒推所有上古经历。
