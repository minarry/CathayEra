# 九州志生命与神圣存在

本文维护气、灵、魂的实体机制，以及人、精、妖、鬼、神、仙的分类和信仰关系。灵魂实体性来自创作者明确澄清；具体转化与身份解释属于推荐工作稿，见[待决 D03](../00_项目管理/决策与待办.md#d03)。规则内涵引用[规则与存在](规则与存在.md)，个体历史引用[神话与传说事件](../02_世界历史/神话与传说事件.md)。

<a id="life-01"></a>
## 气灵魂的实体性

### 气

气是实际存在、参与流动与转化的媒介，有来源、状态、依附范围、相互作用与终结方式。不只等于普通空气，也不作为无来源的无限法力。

### 灵

灵是一类真实存在，是生灵形成与维持自身的重要基础。生长、感应、自行组织是其典型作用，不是灵本身的全部定义。

一团灵、一株植物中的灵、已经离开原宿主而暂时存续的灵，可以有不同状态。它们需要来源、容身方式、活动条件和终结过程。看不见、不能用手触碰，并不意味着没有位置、没有作用或永不损耗。

### 魂

魂是生灵经历真实转化后形成的另一类存在，能够承载经历、执念与一定程度的自我连续性，也是神性形成的基础。

魂具有记忆，不等于魂只是记忆。抄写一份日记、复制一段声音或重建行为模式，不会因此自动产生原来的魂；魂真实存在，也不意味着它的记忆永不失真或损伤。

最初魂可以主要在生死转化中出现。成熟生命或修行者也可能在生前逐渐稳定魂的结构，但必须说明具体过程，不因作者给角色增加了回忆就宣布其已凝魂。

### 转化与消亡

灵转为魂，需要真实存在经历变化；魂散还灵，也必须说明原魂如何失去结构、哪些部分转入后续生命过程。两种转换都不是纯粹的信息重命名。

实体性不要求引入现实化学中等量守恒的公式，但必须有可追踪的来源、去向和代价。魂能保存多久、受损后剩下什么、是否仍为同一主体，需要生命模块继续细化。

生物体、灵和魂不必在所有时期都一一对应。一位神可能由多个魂组成，魂之间可以保留差异；不能把融合写成既保留每个完整个体、又无条件复制一份完全独立的总神而没有任何过程和代价。

## 魂的去向与身份连续性

| 魂的去向 | 真实发生的过程 | 身份与限制 |
| --- | --- | --- |
| 散解还灵 | 魂的组织瓦解，部分存在经转化回到灵及其他后续状态 | 原来的完整自我不自动继续存在，不能凭旧记录无成本恢复 |
| 阴地凝结 | 魂与环境共同形成凝聚物、痕迹或其他存在 | 不等于魂变成了规则；在早期可参与成则，后世通常只是依既成规则转化 |
| 依附成鬼 | 单个魂找到维持自己的实际依托 | 可以保有人格，仍受损耗、依托及自身执念限制 |
| 众魂成神 | 多个魂与承载共同形成稳定神格 | 需要处理相容性和各个魂的身份变化，不是简单数量相加 |
| 被神摄纳 | 真实魂经联系或强制作用进入神的组织 | 自愿与被迫不同，神可能失控，魂可能反抗或继续保持差异 |
| 特殊复归 | 足够完整的魂与可以继续承载它的生命过程重新结合 | 需写明身体、时间、损伤、来源与代价，不等于复制过去即可复活 |

远古魂聚无处去，可以解释为魂不断形成，而自然散解与转化通路不足。不能因为魂真实存在，就默认其永不消亡；也不能因为灵能够再生，就默认原来的个体一直保留。

轮回若在后世出现，是对这些真实存在的新组织与去向安排，需要后天成则机制。它不是给一条早已有的完整转世制度补一个名字。

魂畏阳火按具体状态理解。无保护散魂、活体中受到调节的魂、成熟神格中的魂和器物内的魂，承受条件各不相同。火神的成立需要足以组织和承受相关作用的神格过程；不能把未经组织的游魂直接投入火中就算成神。【阳】【火】不等于任何可见光或微弱温热。

检查生死场景时分别回答：实际保留了什么、转化了什么、是否仍为同一主体。保存记忆不能代替保存魂；魂散还灵不能自动解释为原人格转世。当前尚未确定统一的身份连续性判据和普遍复归期限。

<a id="life-03"></a>
## 金属与魂的联系

原初魂的凝结参与【金】的形成，不意味着后世所有金属都必须由一批新的死者逐一转化而来。【金】一旦成为本源，可以参与多种符合条件的存在生成。

可以继续保留普通矿、具有特殊灵魂痕迹的灵矿、实际束缚了魂的封魂之物三类。第三类才默认涉及真实人格被拘束的问题，前两类不能一概按囚魂处理。

冶炼作用于材料和其中实际存在的灵魂痕迹，不是在熔化【金】规则。焚魂作用于魂及其维持结构，不是在消灭魂的全部存在可能。

<a id="life-04"></a>
## 生命谱系与存在状态

| 类别 | 定义重点 | 不能直接推出的结论 |
| --- | --- | --- |
| 人 | 女娲造出的、能够在有限生命中协调五行的谱系 | 生来全能，或拥有比其他生命更高的道德地位 |
| 植与兽 | 不同生命形态与演化路径 | 植物只能被动、兽类只能争斗 |
| 精与妖 | 某些植物、兽及相关生命形成较稳定自我并主动修习的状态 | 获得自觉必须变成人形；妖天然邪恶 |
| 精灵与兽人 | 原图中保留的衍生生命方向 | 全部连线都已确定为生物杂交，或可以直接使用西式种族设定 |
| 鬼 | 单个魂在死后相对独立地存续 | 已经拥有某一世界规则的控制权 |
| 神 | 众魂与实际依托形成稳定神圣主体 | 成为同名本源的化身、主人或唯一来源 |
| 仙 | 活着的生命维持形气灵魂连续性的修习成就 | 没有代价、永不受伤、可以违背原始规则 |

这些维度可以交叉。人能成仙，死后也可能成鬼；多个魂形成神时需要记录身份关系。相较强弱，要看具体来源、承载、规模和条件，不能只按名称排位。

女娲的“五行齐”是一种稳定协调能力。其他生命可通过修习、演化或共同生活形成不同程度的协调，不必归入唯一的人族道路。

“精”目前优先沿植物或相关非兽生命觉醒路径理解，“妖”沿兽类觉醒路径理解；两者的覆盖范围仍可细化。成仙描述活着的形、气、灵、魂持续维持的成就，仍需外部资源，也可能受伤与衰散。生前凝魂的普及程度不得跨时代自动通用。

女娲造出新的生命主体，人的魂不因创造关系自动归属于女娲，人也不是她的分身。具体造人经过只在[女娲事件](../02_世界历史/神话与传说事件.md#event-nuwa)维护。

## 众魂成神与信仰

第一位神之前没有成熟宗教，真实众魂仍可以因类似经历、愿望与相容条件而汇聚。成神需要存在层面的组织过程，不能把“许多生命想过同一件事”直接写成无条件生成神。

神出现以后，信仰、名字、祭礼和真实生活依赖可以加强魂的稳定与归向。它们有实际作用，但信徒人数不直接等于战力；魂的完整性、相容性、连接和承载都参与结果。

杀戮改变现有生命、灵与魂的去向，不自动创造等量可用力量。战争可以使一些神短期获得更多死魂，也会破坏未来信众、产生抵抗和冲突。守护、教育与长期共同生活因此同样能成为真实的成神与强盛道路。

神属某行，描述主要依托和作用倾向，不是它拥有一条方形规则。火神消亡不会删除【火】，女娲沉寂不会删除【土】，金神也不能将自己的守旧偏好直接宣布为【金】的全部含义。

活人的祭礼、供奉、协作与真实生活联系也可以参与维持神，不把死亡设为唯一供给。异质魂可能造成神格内部争执、分裂与盲点；执念强的魂也可能拒绝或抵抗收纳。具体能力仍取决于来源、规模、组织与承载。

神格是该神存在的组织结构，神位是称号或职衔；具体区分见[本体定义](规则与存在.md#ont-01)。神的存在、教团权力与自然现象应分别记录。某个教团可以在神衰弱后继续掌权，一种自然异象也可能被误认成神迹。

<a id="life-06"></a>
## 修习与宗教的预留方向

创作者提出三类修习方向，尚未形成完整能力体系：研究并运用五行，维持与转化魂及探索轮回，以及强化灵与身体。不同流派可以争论先天条件、后天教化、死后延续和个人选择。

建议把现实宗教名称保留在作者灵感笔记，把实际行为落实为《九州志》中的具体教团、派别和人物。某个轮回教团可以真心救度，也可以有支派利用轮回攫取魂；二者共享部分技术，却作出不同选择。这样能发展内部改革、制度腐化和真正有价值的信仰生活。

“不修五行躯体”也不等于“不需要修炼”。魂道依然需要认识、保持和改变魂的结构，轮回不能自然成为无成本保留全部记忆和力量的永生通道。

原稿关于阐、截、东方、西方、萨满及参考小说的标签，暂不全部确认为正式宗派名称或宗教谱系；先让它们各自拥有明确的机制、成员生活与内部争论。

组织出现年代与制度更替仅在[时代总表](../02_世界历史/创世与时代总表.md#history-later)维护。轮回或盟誓若被展开为真实后天法则，先按成则条件审查，再建立自己的主条目；不以教义名称替代机制。
