# 规则与存在

本文维护世界的基本概念。生命分类见[生命与神圣存在](生命与神圣存在.md)，补天如何运用这些概念见[补天法则](补天法则.md)。

<a id="ont-01"></a>
## 规则与存在是两个层面

**规则**决定事物如何形成、变化与相互作用，设定图中用方形表示。**存在**是规则在现实中的交织与呈现，用圆形表示。

【水】与河流不同，【火】与火焰不同，【土】与大地不同。日月、山川、生灵、神祇都属于存在。灵与魂也是真实存在，有来源、变化和消亡；看不见、摸不到，不等于只是比喻或信息。

神能够认识、运用或承载某种规则，但神的诞生不等于该规则诞生，神的死亡也不使该规则消失。崇拜对象、规则与具体神灵必须分别说明。

<a id="ont-02"></a>
## 原始、先天与后天

| 层次 | 内容 | 约束 |
| --- | --- | --- |
| 原始规则 | 时、空、阴、阳 | 构成世界运行的最基本条件；后来的力量不能任意取消这些条件 |
| 先天规则 | 金、木、水、火、土 | 在世界早期演化中形成并稳定为普遍基础；“先天”不要求五者同时出现 |
| 后天规则 | 世界发展中可能形成的新关系 | 依赖既有规则和现实条件，具有适用范围；不能凭一个人或一位神的意愿覆盖上层规则 |

保留木、金与早期生灵、魂的演变密切相关的方向。五行成形的精确年代与每一步过程尚未定稿；到《补天记》故事开始时，五行规则已经存在。长篇终点完成的是生死循环与五神格局，不是临时创造缺失的元素。

<a id="ont-03"></a>
## 时空、阴阳与因果

时让变化具有先后，空让存在具有位置与关系。日月轮转使时间有了可感知的节律，大地展开使空间有了可居处的形态；日月停转或一片土地毁灭，不等于时空规则本身消失。

阴阳描述相对的趋向与状态：内敛和外发、潜藏和显现、静养和活动。它们相互依存、可以转化。阴不等于邪恶，阳不等于正义；偏阴的九黎仍是活着的人。

因果是行为与后果之间的联系。执念可能由爱、恐惧、愧疚、仇恨或未竟之事形成，不能把所有魂的困境归为罪有应得。“业”可作为世界内解释；暂不将它与物理学的“熵”等同，也不增加一个通用善恶数值。

<a id="ont-04"></a>
## 五行的内涵

以下为《九州志》的创作性取义，用来引导能力与生活设计，不宣称穷尽传统哲学。

| 规则 | 核心取义 | 可以引出的现实联系 |
| --- | --- | --- |
| 土 | 承载、孕育、安定 | 身体、家园、耕作、容纳与归处 |
| 水 | 流动、润养、渗透 | 河流、交通、交换、适应与流离 |
| 火 | 发动、转化、显现 | 炊煮、温暖、冶炼、创造与毁伤 |
| 木 | 生长、延续、舒展 | 繁衍、修复、群落、传承与新生 |
| 金 | 凝聚、分辨、收束 | 器物、边界、保存、分离与终结 |

这不是阵营性格表。火的共同体可以守护，水的共同体可以封闭；金既可束缚，也可帮助一个魂不再被其他声音淹没。具体法术须说明媒介、作用与代价，不能只凭词义无限延伸。

<a id="ont-06"></a>
## 新规则可以怎样出现

存在长期变化，可以形成新的稳定关系。只有当关系能在相应条件下反复成立、超出单个施术者而持续发挥作用，才有理由称为后天规则。一次奇迹、一项技术、一条社会命令都不自动成则。

新增规则时只需回答四件事：它依赖什么；在什么范围有效；需要什么条件或代价；失效会怎样。不能创造无来源的灵魂，不能靠改名绕过已有约束，也不能以“更高规则”为结局临时解围。

<a id="ont-07"></a>
## 写作时的用法

先判断描述的是规则、存在，还是角色对它的解释。规则正文只在这里维护；一个地区对规则的理解可以有偏差，地方传说也可以互相矛盾，但作者不能把认知差异当作随意改变事实的理由。
