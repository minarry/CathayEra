# 补天法则

本文合并原“魂路与归还法则”的必要内容，只维护《补天记》的问题、手段和结局边界。事件经过见[故事总纲](../03_故事创作/补天长篇/故事总纲.md)，灵魂定义见[生命与神圣存在](生命与神圣存在.md)。

<a id="law-bt-01"></a>
<a id="law-support"></a>
## 补天要完成什么

生灵已经能够繁衍、死亡，死后的魂却缺少通畅的去路。积聚的魂形成鬼和灾难；活人的战争、压迫与未尽之事又不断加重这个困境。

**补天是使生与死重新连接，补全尚不完整的循环。**它可以留下壮观的天地变化，但核心成就必须落实为魂的处境改变。本书以这次补天为终点。

<a id="return-region"></a>
## 同一世界中的冥界

“冥界”指魂容易汇聚、活人难以适应的区域，和地表属于同一个世界。两地之间有可以进入、离开的联系，具体地理与通道随故事需要确定；不预设三个封闭位面或一套已经成熟的地府官制。

九黎能够在这里延续生活，与偏阴体质及其积累的经验有关。土族主角误入并生还是需要写出具体条件的经历，不说明所有活人都能自由往来。

<a id="return-state"></a>
## 魂灾的两重来源

一是世界尚未完善的生死循环，二是活人持续制造的伤害、死亡和执念。解除某个执念可能缓解个体痛苦，却不能独自解决所有魂的积聚；疏通循环也不能替战争的发动者、迫害者或控制者免除责任。

因此，消灭九黎、杀死某位神、摧毁一座仪式设施，都不能直接等同补天成功。

<a id="return-tech"></a>
## 稳定鬼与控制鬼

九黎与鬼中的特殊人物共同发展出稳定鬼、驱使鬼和释放其力量的技艺。救助与利用可以出现在同一套器物、同一段关系中，但三个作用仍可辨别。

稳定可能真实减轻痛苦，控制也可能真实剥夺选择。一部分九黎以“重返人间、解决执念便能解脱”的承诺利用鬼；有人确实得到过缓解，正使这个承诺更可信。不能因此写成所有帮助都是骗局，也不能用帮助过对方来抵销后续伤害。

拆除控制可能同时破坏维持稳定的条件。这是角色需要面对的困境，不是宣布奴役不可替代；替代办法要通过认识、尝试、合作及实际代价逐步找到。具体器物和限制只在使用它的情节中确定。

<a id="return-stones"></a>
## 五色石与五行协同

五色石保留为女娲交付任务和游历过程中的具体对象，有获得、携带、使用的现实经过。它们与五行及补天相关；来历、取得方式和各自功能暂不写死。

五色石不能仅是凑齐后自动通关的钥匙。旅程中对生死的理解、人物建立或破坏的关系，以及双主角掌握力量的过程，都必须影响最后能怎样使用它们。五行各自的取义见[规则与存在](规则与存在.md#ont-04)，不在这里另创一张重复的能力表。

<a id="law-nuwa"></a>
## 女娲的接触

保留土族主角**首次离开冥界后接触女娲、接受五色石任务**的时点。沉睡中的女娲以何种方式接触主角、能够说明多少，尚未确定；不能直接写成她已经彻底苏醒、随时能解决全部危机。

后期回到土族圣地，是重看家园、遗存与最初任务的机会。可以发生第二次接触，但不把它当成已经确定的必经事件，也不推迟或替换前一次相遇。

<a id="return-law"></a>
<a id="return-choice"></a>
## 结局必须兑现的改变

补天之后，魂应真正获得摆脱无尽淤积、走向转化与归处的可能，世界的生死联系能够持续运作。具体方式要由此前情节建立，不能在终章突然宣布一种没有来由的新能力。

不同魂与鬼未必选择相同的结局。已经形成独立意愿的鬼不能被统一当作材料拆散；接受救助也不等于同意交出全部记忆或自主性。故事须让这些差异影响主角的选择，但暂不预设一套完整的审判、留驻和管理制度。

修复循环不等于人人永生、所有死者复活、仇恨瞬间消散。它带来的是可以改变的未来，而不是取消发生过的一切。

<a id="law-limits"></a>
<a id="law-new-gods"></a>
## 神力与代价

双主角成神是故事终点之一，成神后的力量、责任和私人生活应有后果。具体代价尚未选定，应从已经建立的人物关系与能力中产生。

神可以直接参与事件；能够做什么、为何未做，要在相关情节中给出实际条件和动机。未知睡因、万能神谕与突然降临的先天神，都不能替代主角完成结局。
