# 九州志补天法则

<a id="law-bt-01"></a>

条目编号：LAW-BT-01。创作者明确的主线是女娲补天后建立神不能直接现身人界的限制，并受损沉寂。以下完整神格判据、神域、五色补材和承载方式均为推荐解释，尚待[决策 D04](../00_项目管理/决策与待办.md#d04)确定。

本页是补天机制的唯一维护位置。事发原因与历史影响见[补天事件](../02_世界历史/神话与传说事件.md#event-bt)，成立时间见[时代总表](../02_世界历史/创世与时代总表.md#history-eras)。

## 修复对象与新增关系

本方案中的“天”，包括依规则维持阴阳周期、气的运行以及天地稳定作用的真实结构；其中有些难以被普通感官察觉，但仍属于存在。水火神战损伤的是这些结构和具体作用关系，不是击碎原始【时】【空】后让同一场战争继续进行。

补天同时完成两件事：修复被破坏的持续条件，并改变完整神格与人间之间的作用方式。第一件事挽救当下，第二件事避免同样规模的神战轻易重演。

此条目依[一般成则条件](规则与存在.md#ont-06)提出后天规则方案。新增关系由修复材料、女娲投入与真实承载延续；其上位约束不因覆盖范围或持续时间改变。

空间关系的推荐补充是：补天使完整神格收束在其元素依托与聚魂结构形成的神域中。神域属于同一个世界，但与众生以身体共同生活的人界隔开；它不简单等于天空某座宫殿或地底更深的一层洞穴。水火等元素仍在人界流转，与其相关的完整神圣自我却不能随元素一起自由进入。

这给神的存续和彼此联系留下位置，也不要求提前建成完整天庭或地府。凡人、仙或鬼如何抵达神域，需要单独规定，不能靠普通行走或临时开门绕过界限。

## 成立条件与实际代价

她是最早形成完整五行调节的神，又长期依托承担众生的大地，因此能够观察、连接并调整其他神偏重一行而忽视的关系。

推荐采用“五色补材”作为能够承担不同五行作用的实际材料方案。它们是存在，不是五块被切下来的规则。此时五行早已齐备，材料可以体现木金相关作用，并不要求木神、金神已经成熟，更不意味着女娲吸收了未来的五位主神。

补天需要真实的五行材料、适当地点、长期准备和代价。女娲将自身相当一部分神格及其作用固定在修复结构中，失去原先能够自由行动的能力。参与者及具体场景由事件主条目维护。

## 适用范围与行为判例

推荐准确表述为：**完整、连续、能够自行行使全部神格的神圣主体，不得直接进入并占据人界。**

禁限判断的是存在方式，不能靠把神体缩小成人、取一个凡人名字或穿过一扇普通门绕过。

| 行为 | 补天后的处理 |
| --- | --- |
| 完整神格直接降临并自由施力 | 被禁限阻隔，不作为日常可行行为 |
| 把完整神格装进人、兽、器物或所谓小化身 | 仍属直接降临，不能绕过 |
| 有限神谕、梦中信息、征兆 | 可以发生，但需要联系、接收者与解释，可能受到误解和阻断 |
| 少量局部力量作用于真实依托 | 可以发生，受依托承受能力、范围和供给限制，不能把所有力量压入一点 |
| 教授术法、选择祭司、诱导氏族决策 | 可以发生，人间参与者仍有自己的判断、责任与利益 |
| 遗器保存有限效果 | 可以存在，需记录来源、容量、恢复条件与损坏方式 |
| 完整自我脱离原神格后转世 | 属于另一种重大变更，必须失去原神格及相关完整权限，不能作为保留一切能力的便捷化身 |
| 破坏补天结构后强行突破 | 可作为重大危机候选，需要可追踪的损坏、准备与世界后果，不能由一句咒语临时打开 |

神迹、神谕和间接赐力不是“神已完整在场”。借助多个祭司也不能自动复制同一神的全部能力，多个联系共同受到神格组织与人界承受条件约束。

## 立规者同受约束

禁限同时约束女娲，她又把大量力量固定在补天结构中。她仍可在条件允许时与其他神联系，或通过已有联系帮助人间，但不能随时抽身降临；那会威胁她所维持的修复成果。

她与木神的协商可以发生在神之间的联系中，再由木神或人间可承受的微弱联系传达。不能因为她是立规者，就让她在故事需要时无限例外。

## 未覆盖的问题

它阻止完整神格直接压入人间，却没有消除信仰竞争、人对神的依赖、魂的滞留和人间自己的欲望。世界因此进入更适合英雄与共同体主动行动的阶段。

这不是补天毫无意义。直接神战受到实质限制，生命获得延续和改变处境的时间，后世才有可能发展新的道路。

## 受损与恢复的边界

承载的分布、局部破坏与禁限强弱之间的关系尚未设计完成。可以研究局部受损改变局部神迹条件的情境，不能先默认破坏任一块补材就能关闭全世界禁限，也不能默认所有局部损坏毫无影响。

恢复必须作用于实际损坏，交代材料、联系、维护者及代价。修补一处后天承载不重新生成原始时空或五行。涉及突破的故事需先明确作用地点、通路、受损范围、持续条件与后果，再写场景。
