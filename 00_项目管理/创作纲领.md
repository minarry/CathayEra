# 九州志创作纲领

本文维护项目目标、已确认的创作基础和创作方法。世界事实、时代年表与协作流程分别由各自的主文档维护，入口见[项目总览](../README.md)。

## 已确认的项目基础

| 编号 | 已确定内容 |
| --- | --- |
| B01 | 项目名称为《九州志》，目标是长期成长为能够支撑大量游戏、视频等创作的世界观体系。 |
| B02 | 世界属于东方奇幻，需要形成自己的设定逻辑，不能直接套用 DND 种族或中古战锤等现有框架。 |
| B03 | 历史主体分为神话时代、传说时代、史诗时代；史诗时代之后另有作为第一篇故事起点的近代。 |
| B04 | 神话时代涵盖创世与早期演化，主要行动者包括神、半神、先天力量及圣兽；重大事件参与形成地理、力量与元素体系。 |
| B05 | 传说时代的世界架构、力量元素与种族基本稳定，但治理、力量传承及文化传统仍在形成；神仍存在，活动减少，以可见或隐藏的间接方式影响世界。 |
| B06 | 史诗时代的种族、治理机制和国家结构基本成熟，经历过朝代更替，具有最广泛的后续创作空间。 |
| B07 | 第一篇故事开始于近代，基本遵循史诗时代的规则。 |
| B08 | 整体气质为“壮阔、有烟火气、保留希望”。 |

以上为创作者直接确定的内容。项目目录沿用“九洲志”，作品名称使用“九州志”。参考作品提供创作方向，不自动把其中的人物、种族、剧情和宇宙规则纳入本项目。

## 共同创作原则

以下原则延续前稿，作为工作建议；不把主题偏好升级为世界中的自然法则。

建议把项目定位为：**一个由神话塑造、由众生继承并不断改变的东方奇幻世界。**

“神话如何成为今日生活的一部分”可以作为贯穿各时代的创作问题。创世事件留下河流与山脉，英雄的胜利形成制度，制度在漫长历史中产生新的受益者和代价，近代人物因此面对真实而具体的选择。

建议所有作品共享以下创作约束：

1. **世界有因果。** 重大力量必须影响资源、战争、交通、生产或社会组织。能够普遍使用的能力，不能只在战斗时出现。
2. **东方性进入制度与日常。** 从人与山川的关系、祖先与后人的责任、礼法和秩序、地方共同体、身体修习、历法节律等关系中创造规则，再形成视觉和词汇。
3. **众生具有不同立场。** 生理差异不直接决定善恶，文明内部存在阶层、区域、学派和时代分歧。
4. **大人物受到条件约束。** 强大者仍有行动范围、资源、信息、承诺或代价上的限制，普通人的组织和选择能够改变结果。
5. **每个地区能够独立生长。** 地区可以承载自己的悬疑、冒险、战争、家族史或生活故事，同时与共享世界发生联系。
6. **故事承担自身结局。** 单篇可以留下世界谜题，但其核心人物困境应得到回应；理解当前故事不应要求先读完整百科。
7. **新增设定带来新选择。** 优先增加关系、限制、冲突和生活方式；谨慎增加功能相同的新神、新族和新境界。

“继承与改制”“人与山川”“记忆与名分”保留为可并存的主题方向，也容纳创造、照护、探索与延续。单篇作品不必给出统一结论。

## 内容架构

| 层级 | 内容 | 变更原则 |
| --- | --- | --- |
| 创作宪章 | 主题方向、东方性原则、叙事体验、明确边界 | 由发起人和总编统筹，变更需解释全项目影响 |
| 世界底层规则 | 世界结构、生命与死亡、力量来源、时间和空间、不可突破的限制 | 最少而明确；新增例外必须评审 |
| 时代与历史 | 时代规则、转折事件、纪年换算、重大迁徙和制度形成 | 区分确定事实、作者尚未决定的部分、世界内传说 |
| 地区与文明 | 地理生态、智慧族群、文化、国家、组织、经济与日常 | 在共同约束内由模块负责人扩展 |
| 故事与人物 | 人物关系、事件、冲突、遗迹、物品、场景 | 绑定具体时代、区域和正典版本 |
| 媒介表达 | 小说、影像、游戏规则、美术、声音、交互 | 允许形式差异；改变世界事实时标记分支并评审 |

这是内容层次，不是规则的本体层级。模块负责人和具体文件归属统一见[协作与版本管理](协作与版本管理.md#doc-ownership)。游戏平衡数值、镜头夸张和世界真实能力应分别记录，改编不能不经说明地改变公共事实。

## 东方奇幻的原创方法

### 从关系推导设定

建议采用“关系问题 → 世界机制 → 社会后果 → 可见细节 → 人物冲突”的顺序。

例如“人如何与有回应的山川共处”可以发展成地域性的力量使用条件，进一步影响聚落选址、渡河许可、农业祭期和治水责任。读者最终看到的是一个人为什么必须绕路、一户人为什么搬迁，以及一座城为什么发生争执。

神话、礼制、方术、志怪和古典文本可以提供创作母题。应记录采用的是何种问题或结构、进行了什么改造、产生了什么新的因果。不同来源的观念不必被强行合并成一套自古一致的体系。

### 族群、文明、国家与组织分别设计

| 对象 | 决定的内容 | 不应自动决定的内容 |
| --- | --- | --- |
| 智慧族群 | 身体、感知、寿命、繁衍、环境适应及可能的先天能力 | 全体成员的道德、职业、政治立场 |
| 文明与文化 | 语言、记忆、价值争论、礼俗、教育、传承 | 只能由单一族群参与，或永远不变 |
| 国家与政体 | 领土、治理、税役、军队、法律、合法性 | 与某一文明或族群完全重合 |
| 组织与学派 | 目标、成员资格、知识、资源及内部规则 | 所有成员都忠诚或拥有相同观点 |

一种族群可以建立不同国家，一个国家可以容纳多个族群；同一传统也可以被敌对势力分别解释。是否存在例外，由具体历史解释。

族群设计先回答繁衍、食物、睡眠、寿命、学习速度、栖居环境、资源需求和与其他生命交换什么。长寿与特殊感知必须在教育、财产、政治与亲属关系中产生后果。

不同修习传统可以共享底层约束，在媒介、训练、组织与价值观上发展差异。其能力定义使用[术法模板](创作模板.md#template-power)，不从五行数量直接推出职业、境界或族群数量。

## 历史进入当下生活

重大事件至少留下地理、生态、人口、制度、记忆、资源或器物中的一种持续影响。今天的人物应能实际遭遇这种遗产，并通过选择改变它。

古代制度可以曾经有效，后来因环境和社会变化而需要调整。各地保留独立历史，不让全部矛盾都归于一个幕后神、一个帝国或同一场神战。

## 可持续的故事空间

每个重点地区至少提供：一个可持续的生计系统、两种以上有合理诉求的力量、一项历史遗产、一种局部异常、一个普通人可进入的职业视角，以及若干无需拯救世界也成立的冲突。

| 故事尺度 | 典型冲突 | 适合承载的世界内容 |
| --- | --- | --- |
| 个体与家庭 | 继承、失约、身份、手艺、生死 | 习俗、家庭结构、力量代价与日常生活 |
| 地方与组织 | 水权、迁徙、商路、学派分歧、地方灾害 | 地理、资源、组织与治理 |
| 国家与文明 | 战争、改革、联盟、正统争议 | 政体、历史记忆、文明互动 |
| 跨时代与世界 | 旧秩序失效、重大规则变化 | 神话遗产、时代转折与底层规则 |

优先让前三种尺度不断产生新故事。跨时代事件较少发生，并且发生后必须改变世界状态，不能在下一部作品中恢复原样。

游戏可以从探索、群体协作、政治选择或地方治理中提取玩法；影像可以通过角色行动和场景表现规则。具体媒介的体验由作品团队决定，不必将所有内容都改造成战斗数值。
