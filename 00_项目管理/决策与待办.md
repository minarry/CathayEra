# 九州志决策与待办

此页只维护方案的选择状态、待补条件和任务依赖。完整设定写在对应主文档。下列 D 项均未获得逐项最终确认；“推荐”仅指当前推演采用的工作解释。当前没有实际分派任务或确定工期。

## 待决项目

<a id="d01"></a>
### D01 规则层级与生成先后

状态：推荐工作解释。主条目：[规则层级](../01_世界设定/规则与存在.md#ont-02)。当前按木金后起、定型后同属本源推进；备选是五行开辟时全部成立，生命仅使木金显化。若选择备选，必须同时改创世表与成则案例，不能两条路线混用。

<a id="d02"></a>
### D02 五行定型

状态：边界有推荐，机制未定。主条目：[成则](../01_世界设定/规则与存在.md#ont-06)。待解释传播、稳定与脱离原初个例的过程，以及定型为何形成后世创作边界。不得宣称已从原始四则证明恰有五行。

<a id="d03"></a>
### D03 魂的身份与转化

状态：实体性已由创作者明确；具体身份判据未定。主条目：[魂的去向](../01_世界设定/生命与神圣存在.md#life-02)。待确定受损、聚合、分解和复归时哪些条件保留主体；影响鬼、神、仙与轮回。实体性本身不重新表决。

<a id="d04"></a>
### D04 补天的准确机制

状态：补天禁神主线来自创作者；完整神格判据、神域、材料与结构为推荐。主条目：[补天法则](../01_世界设定/补天法则.md#law-bt-01)。待确定承载分布、局部损坏、有限赐力尺度及恢复条件；不提前用单件补材控制全世界。

<a id="d05"></a>
### D05 金神的依托

状态：共盟之器为优先候选。主条目：[金神事件](../02_世界历史/神话与传说事件.md#event-gold)。兵冢或共同丧葬地保留为替代方向；选定后才细化其与水神、炎帝、轩辕的事件链。

<a id="d06"></a>
### D06 时代分界

状态：三大时代与近代定位已明确，具体分界待定。主条目：[时代总表](../02_世界历史/创世与时代总表.md#history-eras)。当前以补天、封神后秩序稳定为主要分界；需检验治理成熟度、主角类型与能力变化是否共同支持这种分期。

<a id="d07"></a>
### D07 轩辕五帝与建夏

状态：解决原输入两次建夏的推荐调整。主条目：[称号与王朝衔接](../02_世界历史/创世与时代总表.md#history-names)。当前分开轩辕建立五帝秩序与禹后进入夏；具体五帝名单、继承关系、夏的建立者未定。

<a id="d08"></a>
### D08 衍生生命

状态：原图给出方向，形成方式未定。主条目：[生命分类](../01_世界设定/生命与神圣存在.md#life-04)。精灵、兽人与人的连线尚不等于生物杂交、父子血缘或西式种族。先比较生命条件与社会后果，再确定名称和谱系。

<a id="d09"></a>
### D09 神格的完整程度

状态：成熟主神协调五行是当前解释，小神与未成熟神格尚待细化。主条目：[众魂成神](../01_世界设定/生命与神圣存在.md#life-05)。需要处理地方灵性、单魂参与神格的身份变化，以及与补天判据的衔接。

<a id="d10"></a>
### D10 后世修习与后天规则

状态：机制方向已提出，具体制度未定。修习内容归[生命文档](../01_世界设定/生命与神圣存在.md#life-06)，形成顺序归[后世历史](../02_世界历史/创世与时代总表.md#history-later)。轮回、盟誓或自然生态成则可选一项试验，先证明新增关系，再独立建法则主条目。巫道转折和封神不能仅靠改称号成立。

<a id="d11"></a>
### D11 九州地理与首作条件

状态：具体地图、媒介、体量、地区、人物和近代能力均未选定。九州形成方向见[历史总表](../02_世界历史/创世与时代总表.md#history-names)。先确定首作必需的交通、通信、医治与生计条件，再选局部舞台。见川、蜕民、岫生及旧能力尺度只在归档中保留，不是默认首作配置。

## 建设顺序与完成门槛

1. 固定当前工作依据：关键术语、已明确输入与推荐方案能被分别引用。
2. 完成首作必需的规则：能够回答生命、死亡、神干预与常用能力问题，不依靠临时增加例外。
3. 建立局部地区：解释粮食、资源、交通、权力和主要利益冲突；不提前填满全球地图。
4. 写出完整企划与三个关键场景：人物目标、限制、选择和结局可被不读百科的读者理解。
5. 发布首个世界正典版本：阻断项已解决，主条目、来源、状态、负责人及作品绑定齐全。
6. 扩展第二个地区或异时故事：能够复用规则，又形成不同生活与冲突。

探索可以交错推进，正式合并前检查依赖变化。完整神谱、全部族群、全球精细地图、所有语言和招式列表可继续留白，不阻塞不依赖它们的任务。
