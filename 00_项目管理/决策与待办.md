# 九州志决策与待办

这里只保留会实际影响《补天记》写作的少量问题。现行设定直接查[主文档](../README.md)，不再把每个已写明的概念都挂成待决事项。

<a id="bt-decisions"></a>
## 当前创作目标

完成九州志的第一本小说《补天记》，并通过全书传递六方面的基础认识，详见[总纲](../03_故事创作/补天长篇/故事总纲.md#story-world)。精简后的主线继续采用；未定部分可用候选试写，无须等待所有问题都有答案才能写人物与生活。

## 当前需要深化的问题

<a id="d03"></a>
### D03 一个魂或鬼怎样得到救助

状态：边界待通过情节明确。

要区分缓解执念、维持稳定、分离纠缠及继续转化，尤其要看已经形成独立意愿的鬼怎样选择。不先制定包办所有情况的身份公式。回写[生命](../01_世界设定/生命与神圣存在.md#life-02)与[补天法则](../01_世界设定/补天法则.md#return-choice)。

<a id="d12"></a>
### D12 先天神的沉睡与女娲接触

状态：原因与接触方式未定。

伏羲、女娲的睡因不能靠临时补述替结局解围。优先确定主角第一次接触女娲时能遇见什么、知道多少；若后续要围绕睡因布置悬疑，再先选作者答案。回写[女娲接触](../01_世界设定/补天法则.md#law-nuwa)和[伏笔](../03_故事创作/补天长篇/伏笔与揭示.md)。

<a id="d14"></a>
### D14 五色石与补天的具体方法

状态：对象和目标明确，过程未定。

五色石怎样取得、能做什么，旅程中的理解与能力怎样使它们发挥作用，仍需设计。方法要回应魂灾，且能在前文建立；不预设完整的节点网络、容量公式和管理制度。回写[补天法则](../01_世界设定/补天法则.md#return-stones)与[故事总纲](../03_故事创作/补天长篇/故事总纲.md)。

<a id="d15"></a>
### D15 成神的代价与人物后续

状态：双主角成为土金二神明确，具体后果未定。

从人物真正珍惜的生活出发选择代价，既让胜利有重量，也让希望成立。水火木三神的最终处境一并随剧情确定，不预定必死、换代或永远被困。回写[结局](../03_故事创作/补天长篇/故事总纲.md#story-finish)。

<a id="d16"></a>
### D16 双主角的私人愿望与关系

状态：身份方向明确，具体人物尚待塑造。

确定他们各自想守住的生活、如何相遇、为什么合作及在哪里分歧；再选择姓名、性别、亲缘和可能的情感关系。人物经历决定故事时长，不以固定卷数倒推。回写[人物与冲突](../03_故事创作/补天长篇/人物与冲突.md#story-leads)。
