# 九州志创作模板

本文集中维护条目字段、专项卡和 AI 任务书。按任务选择必要字段；未知项写“未定”，未取得资料写“缺少依据”，有意留白注明边界。状态定义和流程只引用[协作与版本管理](协作与版本管理.md)。

## 使用与编号

先填通用卡，再添加与对象匹配的专项卡。规则和存在的判别依据见[本体定义](../01_世界设定/规则与存在.md#ont-01)，不能在模板里另行创造定义。编号采用类型前缀与固定序号，改名不换编号；下文 `GEO-001` 等是格式示例，尚无对应实体条目。当前主文档的稳定章节锚点也可作为引用定位。

<a id="template-general"></a>
## 设定条目通用卡

| 字段 | 填写内容 |
| --- | --- |
| 唯一编号与修订号 | 例如 GEO-001，修订 1；示例不代表已经建立对应条目 |
| 名称、别名与类型 | 标准名称、其他称呼、地理或人物等类型 |
| 归属模块与负责人 | 一个主要归属；列出协作模块 |
| 工作状态 | 依[协作状态](协作与版本管理.md#content-status)填写 |
| 一句话说明 | 这个对象是什么，为什么值得被记录 |
| 适用时代与范围 | 生效起止、地域范围；尚不确定时记录范围或相对顺序 |
| 核心断言 | 每行一个事实或提案；标明作者层事实、世界内说法或创作留白 |
| 真相决策与可见性 | 分开填写真相是否已定和可见范围 |
| 来源 | 条目编号与修订号、作品章节、批准记录；原创内容写“原创候选” |
| 依赖 | 使用了哪些规则、地区、事件和人物 |
| 关系 | 本条目造成、继承、位于、参与、控制或反对什么 |
| 具体内容 | 按对象类型补充必要信息 |
| 限制与例外 | 不成立的情形、使用条件、禁止推导的结论 |
| 故事用途 | 至少一个可发生的冲突或选择；不强求每个基础名词独立产生故事 |
| 影响检查 | 哪些已存在的条目和作品需要复查 |
| 未决问题 | 问题、负责人、在什么任务开始前必须决定 |
| 决策与发布记录 | 批准人、理由、日期、所属正典版本；未批准时留空 |

正式条目与 AI 提示词分开保存。条目的作用是描述世界；提示词的作用是规定某次任务。

## 规则专项卡

以下字段补充通用卡；一般成则判据见[成则](../01_世界设定/规则与存在.md#ont-06)。先说明是在发现旧规则、运用旧规则、创造新存在，还是提出新规则。

| 字段 | 填写要求 |
| --- | --- |
| 对象类别 | 本体只分规则与存在；结构、认识、术式与制度另外记为描述类型，不增设本体类别 |
| 层级 | 原始、本源、后天；与产生时间分开 |
| 发生方式与时间 | 开辟确立、自然演化、主动创设；具体阶段或相对顺序 |
| 规则陈述 | 哪些存在，在什么条件下，会怎样变化；避免只给一个名词 |
| 上位依赖 | 使用了哪些原始和本源关系，明确不可改变的部分 |
| 成则过程 | 在该规则尚未成立前，哪些先驱现象已经能够发生；怎样形成新关系 |
| 实际承载 | 保存并维持关系的存在与结构；本源如何脱离最初个例而普遍成立 |
| 适用对象与范围 | 地点、时代、对象状态、触发条件与排除条件 |
| 来源与代价 | 实际效果的来源、维护、损耗和承担者 |
| 失效与恢复 | 什么被改变会失效，失效后回到什么状态，能否恢复 |
| 相邻规则 | 同层冲突怎样处理，不能同时存在的绝对断言如何限制 |
| 存在与施术者 | 谁在利用或维护规则，不把维护者误记为本源所有者 |
| 验证场景 | 成功、失败、反制和跨界误用各至少一个例子 |

<a id="template-existence"></a>
## 存在专项卡

| 字段 | 填写要求 |
| --- | --- |
| 生成来源与过程 | 实际参与者、材料与阶段，不以规则名称充当库存材料 |
| 参与规则 | 所依赖的规则主条目；先驱阶段不得倒用尚未成立的规则 |
| 实体状态 | 形体、可感知方式、完整或受损状态；不可见不等于抽象性质 |
| 位置与依附 | 在哪里存续，依附什么，如何迁移、脱离或受阻 |
| 相互作用 | 可以感知、影响或被哪些存在影响，范围与条件是什么 |
| 维持与损耗 | 来源、补充、承载、消耗与终结条件 |
| 转化去向 | 生成、聚合、分解之后实际留下什么 |
| 身份连续性 | 是否仍是同一主体，依据与未知处是什么，不能只用记忆相似判断 |

## 术法修习与时代能力卡

| 字段 | 填写要求 |
| --- | --- |
| 术法或传统名称 | 先允许工作名，避免用名称替代机制 |
| 力量来源 | 从何而来，是否有限，怎样补充，能否被占有或转移 |
| 取得与学习 | 谁可以获得，训练条件、时间和失败可能性 |
| 生效条件 | 身体、物质、知识、环境、时令、协作或其他必要条件 |
| 能做什么 | 以可观察结果描述，附作用距离、持续时间与频率 |
| 不能做什么 | 与相近能力的界线，本时代明确禁止的效果 |
| 代价与风险 | 谁支付什么，代价何时发生，是否可以转嫁、逃避或修复 |
| 反制与失败 | 如何阻断、规避、误用，以及失败留下什么后果 |
| 普及程度 | 谁掌握知识，训练和资源由谁控制，普通人能否使用 |
| 社会影响 | 对农业、医治、通信、交通、战争、继承等的影响 |
| 时代变化 | 同一机制在四个时间层次如何不同，原因和残留是什么 |

时代边界表另行记录：

| 对象 | 常规能力 | 个人极限 | 集体能力 | 条件性奇迹 | 禁止项 |
| --- | --- | --- | --- | --- | --- |
| 指定时代、地区与传统 | 待填 | 待填 | 待填 | 条件、代价、频率、反制 | 待填 |

至少写出一次成功使用、一次代价发生和一次被反制的具体场景，再判断规则是否可用于故事。

本卡描述如何使用力量；提出客观新规则时另填规则专项卡。技术、教义与规则不能因为使用了同一个名称就混为一项。

## 神话与历史事件卡

| 字段 | 填写要求 |
| --- | --- |
| 事件名称和编号 | 可用工作名；注明所属时代 |
| 发生条件 | 环境、资源、关系和先前事件如何共同导致它 |
| 行动者 | 目标、能力、限制、彼此关系和信息差 |
| 关键选择 | 谁作出什么不可轻易撤回的选择 |
| 事件经过 | 区分作者层已知事实、候选经过与世界内版本 |
| 时间记录 | 使用的历法、原始日期、标准日期或区间、换算依据与不确定度 |
| 因果顺序 | 即使无法确定年份，也列明必须先于或后于哪些事件 |
| 立即结果 | 改变了什么，谁受益，谁承担代价 |
| 长期遗产 | 地理、生态、人口、制度、力量、器物、记忆中的持续影响 |
| 后世解释 | 哪个群体何时如何讲述，讲述服务于什么诉求 |
| 当前联系 | 如何进入近代人物的生活和选择 |
| 未决范围 | 哪些答案尚未决定，哪些后果已经不能随意改变 |

年代不明时用区间或相对顺序，不能为了年表整齐捏造精确日期。世界公共纪年、地方纪年和“距首作开篇多少年”的编辑参照可以并存，换算关系应单独维护。

## 族群与文明卡

族群卡与文明卡分别建档，通过编号关联。

**族群卡需要回答：** 身体与感知、生命周期、寿命与繁衍、营养和环境需求、先天能力与代价、个体差异、学习与记忆、常见聚居条件、与其他生命的交换关系。至少说明一项生理条件如何影响生活，以及哪些社会形态并非由生理决定。

**文明卡需要回答：** 形成地区与历史、参与的族群和迁入者、语言与命名、亲属关系、生产和交易、教育与知识、礼俗与信仰、死亡与纪念、权威的来源、内部阶层及价值争论、地区和时代变体、对外交流，以及普通人的一天。

两张卡都需要列出“他者对其常见的误解”和“内部不同群体的反驳”。作者层不把这些刻板印象写成全体成员的本性。

## 地区国家与组织卡

| 对象 | 必填问题 |
| --- | --- |
| 地区 | 地形、水文、气候、食物、资源、交通、聚落、危险、季节变化与地图尺度是什么？ |
| 国家 | 治理范围、统治合法性、权力继承、财政、军队、地方关系和制度缺陷是什么？ |
| 组织 | 目标、入会条件、资源、知识、内部派别、活动范围、退出代价和组织盲点是什么？ |
| 故事空间 | 谁需要什么，谁因此受损，哪些手段可行，哪些手段会制造新问题？ |

一个重点地区至少写三个不同尺度的故事入口，并说明从何种普通职业或社会身份能够进入故事。不需要每个入口都指向同一场世界危机。

## 故事企划与作品回写卡

| 字段 | 填写要求 |
| --- | --- |
| 作品目标 | 媒介、目标读者或玩家、体量、希望形成的体验 |
| 版本绑定 | 正典版本、额外获准使用的条目修订号 |
| 时间与地点 | 精确到故事所需程度，必要时标记时间区间 |
| 主角与关系 | 想得到什么、缺少什么、与谁有责任或利益关系 |
| 对立诉求 | 各方有何合理目标，为什么无法同时满足 |
| 核心事件 | 什么打破原有平衡，人物必须在何时作出什么决定 |
| 世界规则的作用 | 哪些能力、制度或环境限制参与冲突，而非只作介绍 |
| 关键选择与结局 | 结果由哪些选择造成，付出什么代价，留下什么变化 |
| 读者所需知识 | 只列理解故事必须知道的内容，注明如何通过行动呈现 |
| 新增设定 | 分开列出公共世界事实、局部细节、角色说法和未确认猜测 |
| 结束后的状态 | 人物、组织、地理或制度发生了什么变化 |
| 后续入口 | 哪些后果可以继续展开，同时保留本作的完整结局 |

正文完成后，逐项核对新增设定。对白中的谎言、角色误解、修辞和梦境，不直接进入作者层事实库。

## AI 创作任务书

以下正文可复制给创作助手，方括号内容由任务负责人填写。

> 你正在协助《九州志》的[模块名称]创作。
>
> 本次目标：[需要解决的问题与具体交付物]。
>
> 使用的世界版本：[版本或尚未建立正典的说明]。
>
> 输入资料：[条目编号、修订号、原文或文件位置]。只将明确标为已发布或本任务获准使用的事实作为约束；候选设定仍是候选。
>
> 时代与地区：[适用范围]。必须遵守：[具体规则]。可以新增：[允许范围]。不得决定或改变：[保留事项]。
>
> 先列出任务相关的已知事实、缺少依据的部分和必要假设。信息不足时，可以提出候选假设，但不得声称它已经属于世界设定。
>
> 按[指定模板]交付。存在重大路线差异时，提供至多三个可比较方案，说明各自对历史、社会和故事的后果；一般细节直接给出一个完整方案。
>
> 区分既有事实、新提案、世界内说法和创作留白。为既有事实附来源位置，为新提案列依赖和影响对象。
>
> 验收条件：[具体条件]。篇幅或工作量：[范围]。
>
> 最后提交：交付正文、待决定事项、跨模块影响、需要审校的风险。不要自行宣布设定已获批准，不要修改任务范围外的主条目。

当前阶段的填写提示：尚无完整正典；填写实际使用的主文档与有关 D 编号待决项。候选方案可以作为本任务假设，不得因被试写采用就标成已批准。默认不把归档纳入输入。

## AI 审校任务书

> 你是《九州志》的审校助手。本次只审查以下候选内容，不替创作者直接定稿。
>
> 审查对象：[条目或作品]。依据：[正典版本、条目和关键原文]。审查范围：[时代、力量、年表、地理、社会因果或叙事等]。
>
> 对每个发现提供：严重程度、问题位置、相关原文及来源、为什么冲突、影响范围、最小修改建议。无法确认时标记“待核实”，不把缺少资料当成已经证明的错误。
>
> 区分硬性矛盾、缺少解释、世界内观点差异、合理留白和审美建议。特别检查新增例外是否取消人物困境，以及普通人的生活是否受到相关力量的合理影响。
>
> 最后列出本次覆盖范围、缺失资料和仍需人类判断的项目。没有发现问题时，也只报告在现有资料与范围内未发现问题。

## 变更申请与决策表单

| 字段 | 填写要求 |
| --- | --- |
| 申请编号与提出者 | 关联具体任务和候选条目 |
| 要解决的问题 | 当前设定妨碍了什么，或存在什么实际冲突 |
| 旧内容与新内容 | 精确列出发生变化的断言，不只附整篇新稿 |
| 变更级别 | 文字、局部、跨模块、核心 |
| 可选方案 | 保留旧设定、局部调整、正式修订等，并说明代价 |
| 影响范围 | 直接依赖、间接依赖、在制作品、已发布作品 |
| 兼容和迁移方案 | 哪些继续有效、哪些重写、是否形成版本分支 |
| 审校结论 | 阻断项及解决情况，尚未解决的疑问 |
| 决策 | 通过、退回或暂缓；批准人、日期和理由 |
| 发布与复查 | 目标版本、实际发布版本、完成复查的对象 |

具体选择和当前任务统一登记在[决策与待办](决策与待办.md)，本页不保存另一份状态表。

## 单次任务交接

- 交付正文或条目，以及清楚的候选状态。
- 本次实际使用的来源与版本。
- 新增、修改和保留的内容分别说明。
- 依赖条目、受影响条目和作品。
- 尚未决定的问题及其下一位负责人。
- 自查结果、审校结果和人类批准记录；未发生的步骤明确留空。

交接材料需要让另一位作者可以继续工作，而不必重新询问整段聊天记录。
